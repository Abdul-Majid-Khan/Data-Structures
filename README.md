# Data Structures & Algorithms

The goal of this repository is to consistently improve my problem-solving skills, strengthen algorithmic thinking, and build a strong understanding of common DSA patterns.

## 👨‍💻 About

I solve DSA problems regularly from platforms such as **LeetCode** and maintain my solutions here for future reference and revision.
